# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

# SETUP INSTRUCTIONS

## 1. Clone the Repo
```
git clone https://github.com/cHANGTEEZY/kanban-board.git
```
## 2. Install Dependencies
```
npm install
```
## 3. Run the Code
```
npm run dev
```

# Technology Choices and Rationale

* React: It is very flexible and has great community support for components
* dnd kit: A modern lightweight drag and drop component for react with minimal codes
* vite: A fast and popular build too for react with hot module replacement

# Know Limitations

* No Dynamic tasks adding feature
* No persistent state management
